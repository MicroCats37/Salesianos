# Salesianos FEST 2026

Sitio web del festival del 21 de noviembre de 2026 en la Asociación Okinawense del Perú, Ate, Lima. Familia, deporte y diversión.

## Contenido

- Portada con identidad gráfica del festival.
- Campeonato, actividades familiares, fiesta, cronograma y paquetes.
- Siete promociones participantes con anuncios originales y botones para compartir por WhatsApp y Facebook, copiar enlace y compartir desde dispositivos compatibles.
- Espacios para transmisión en vivo y auspiciadores.

## Ver y editar

El sitio completo está en la raíz del repositorio. HTML, CSS y JavaScript sin instalación de dependencias.

Para probar localmente:

```sh
python3 -m http.server 8000 
```

Abrir http://localhost:8000.

- `config.js`: enlaces y configuración del evento.
- `community.js`: promociones y publicaciones originales.
- `index.html`: contenido.
- `brand.css` y `styles.css`: estilos.
- `sharing.js`: mensajes para compartir.

## GitHub Pages

En Settings → Pages, seleccionar Deploy from a branch, rama main, carpeta /(root) y guardar. GitHub mostrará el enlace al finalizar la publicación.

Los enlaces de inscripción continúan apuntando a la plataforma oficial salesianosfest.pe. La transmisión y los auspiciadores requieren incorporar los datos definitivos de la organización.

Las imágenes, logotipos y contenidos corresponden a los materiales proporcionados para Salesianos FEST; su inclusión no concede una licencia de reutilización de marca ni de imágenes.
